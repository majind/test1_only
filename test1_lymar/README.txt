папка news_card - шаблон для компонента news.list для 1с Битрикс. Управление сайтом. Бизнес.


УСТАНОВКА:

Для того, чтобы добавить данный шаблон в структуру, нужно скопировать папку news_card в папку компонентов сайта:
<корень_сайта>/local/templates/.default/components/bitrix/news.list/news_cards/

Например, в Docker-сборке этого проекта полный путь на сервере был: /opt/www/local/templates/.default/components/bitrix/news.list/news_cards/

Если данных папок нет в структуре сайта, то создайте в соотсветвии с путём выше. 

ПРИМЕНЕНИЕ:
1. открыть станицу в админке
2. Добавить компонент "Список новостей" (bitrix:news.list)
3. В поле «Шаблон компонента» выберите «Карточки направлений».
4. полсе изменений сохарнить настройки
